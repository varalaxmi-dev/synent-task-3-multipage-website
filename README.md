NovaWeb – Multi-Page Website

About

NovaWeb is a responsive multi-page website developed as part of the Synent internship Task 7.

Pages

- Home
- About
- Services
- Contact

Technologies Used

- HTML5
- CSS3

Features

- Responsive design for different screen sizes
- Navigation between four pages
- Consistent user interface
- Contact form with demo confirmation message

How to Run

1. Download or clone this repository.
2. Open "index.html" in a browser, or use VS Code with Live Server.
3. Navigate between Home, About, Services, and Contact.

Note

The contact form is a front-end demonstration and does not send or store messages on a server.
